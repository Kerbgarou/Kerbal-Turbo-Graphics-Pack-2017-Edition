# Kerbal Turbo Graphics Pack 2017 Edition
Have you ever wondered what Kerbal Space Program would have looked like if Squad made a cloud pack themselves?
This is my best attempt at that. All of the clouds are hand-made in GIMP to vaguely resemble the style of Jools cloud textures. No bump maps, though.

## WARNING

Despite what you may assume through facts and logic, EVE-Redux versions, especially for older KSP versions, are incredibly resource intensive... Especially ones which use muiltiple cloud layers.

You probably won't lag very much using this config pack, but if you're on a laptop like me it is definitely going to get very, very hot. Be warned about that.

## INSTALLATION

1: Extract the TurboGraphics zip file and open it somewhere.

2: Find named folders of the modules you want; For example, if you only want clouds, take the "Clouds" folder.

3: Take the modules you want and place them into your GAMEDATA folder in your Kerbal Space Program 1.3.1 installation.

If something doesn't work, either create an issue or fiddle with it in the EVE editor.
